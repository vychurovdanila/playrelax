# playrelax

Внутренний продукт Makefab: сервис психологической разгрузки и
расслабления через казуальные игры.

Ядро MVP: расслабляющий бесконечный тетрис с медитативным видеофоном.

## Структура
- `BRIEF.md` — суть, позиционирование, scope MVP, roadmap.
- `STATE.md` — текущее состояние и решения.
- `AGENTS.md` — роли и правила.
- `TASKS.md` — очередь задач (1 задача = 1 сессия Cline).
- `src/` — исходники (появятся в сессии 2).
- `assets/` — видео, аудио.
- `prototype/` — исходный прототип как референс, не трогать.
- `docs/` — документация, решения (ADR).

## Статус
Инициализация. См. `STATE.md`.
