# PlayRelax

**PlayRelax** — это иммерсивная веб-платформа для психологической разгрузки и снятия стресса через казуальные игры.

Мы верим, что отдых не должен требовать усилий. Наш сервис сочетает в себе медитативные игровые механики, атмосферное видео и фоновую музыку, создавая идеальное пространство для перезагрузки после рабочего дня.

## 🎮 Концепция

В основе PlayRelax лежит принцип «невозможно проиграть». Мы убрали соревновательный элемент и экраны Game Over. Вместо этого игрок погружается в бесконечный, плавный процесс, который помогает отвлечься от тревожных мыслей и сфокусироваться на моменте.

**Текущий стек:** Ванильный JavaScript + Canvas 2D + HTML5 Audio + Kinescope (видеофон). Без тяжелых фреймворков — только чистый код и максимальная производительность.

## ✨ Текущий функционал (MVP)

- **Бесконечный тетрис:** Умная камера и физика, исключающая проигрыш.
- **Видеофоны:** Плавная смена атмосферных локаций свайпом двумя пальцами (кроссфейд без черных экранов).
- **Фоновая музыка:** Плейлист с динамической подгрузкой треков, случайным порядком и сохранением состояния звука.
- **Кинематографичная пауза:** Размытие фона и фокусировка на мире при остановке игры (два пальца на мобильных, пробел на ПК).
- **Адаптивность:** Полноценная поддержка мобильных устройств (свайпы, тапы) и десктопа.

## 🗺️ Roadmap (Планы по развитию)

Мы только в начале пути. В ближайших планах:

- [ ] **Добавление других казуальных игр:** Пазлы, медитативные аркады, игры на внимание.
- [ ] **Расширение библиотеки миров:** Загрузка пользовательских видеофонов и звуковых дорожек.
- [ ] **Режим «Заставка / Медиа-фон»:** Возможность оставить генеративный мир на экране телевизора или планшета во время отдыха.
- [ ] **PWA-версия:** Установка приложения на домашний экран мобильного устройства без магазинов приложений.
- [ ] **Интеграция с психологами:** Мягкий и геймифицированный мост к профессиональной поддержке для тех, кому это необходимо.

## 🚀 Запуск проекта локально

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/vychurovdanila/playrelax.git
cd playrelax

# 2. Запустите локальный сервер (требуется Python 3)
start-server.bat 8080
# или
python -m http.server 8080 --directory src
```

Откройте http://localhost:8080 в браузере.

## 📁 Медиафайлы

Из-за ограничений Git на размер файлов, аудио и видео не хранятся в репозитории.

Для работы звука создайте папку `src/assets/audio/` и положите туда mp3-файлы.

Список треков управляется через файл `src/assets/audio/playlist.json`.

Видеофоны подгружаются через внешний сервис Kinescope (ссылки в `src/game.js`).
