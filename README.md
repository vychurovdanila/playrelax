# playrelax

Внутренний продукт Makefab: сервис психологической разгрузки и
расслабления через казуальные игры.

Ядро MVP: расслабляющий бесконечный тетрис с медитативным видеофоном.

## Структура
- `BRIEF.md` — суть, позиционирование, scope MVP, roadmap.
- `STATE.md` — текущее состояние и решения.
- `AGENTS.md` — роли и правила.
- `TASKS.md` — очередь задач (1 задача = 1 сессия Cline).
- `src/` — исходники (index.html, styles.css, game.js, audio.js, vendor/).
- `assets/` — видео, аудио.
- `prototype/` — исходный прототип как референс, не трогать.
- `docs/` — документация, решения (ADR).
- `start-server.bat` — запуск локального сервера для тестирования.

## Локальный запуск

Проект — статика (ванильный JS), поэтому для проверки нужен локальный
веб-сервер (открытие `src/index.html` через `file://` не сработает:
не загрузятся модули/аудио).

### Способ 1 — одной кнопкой (Windows)
Запусти двойным кликом `start-server.bat` в корне проекта.
Скрипт сам перейдёт в `src/` и поднимет сервер на порту **8000**
(использует Python, если он есть; иначе `npx serve`).

### Способ 2 — вручную
```bat
cd /d "D:\Makefab\projects\playrelax\src"
python -m http.server 8000
```
Если Python нет:
```bat
cd /d "D:\Makefab\projects\playrelax\src"
npx --yes serve -l 8000
```

### Как открыть
- **На ПК:** http://localhost:8000
- **На телефоне:** http://192.168.0.111:8000
  (телефон и ПК должны быть в одной Wi-Fi сети;
  актуальный IP ПК можно узнать командой `ipconfig`).
- **iOS (Safari):** убедись, что iPhone в той же Wi-Fi сети,
  открой в Safari адрес `http://192.168.0.111:8000`.

Остановить сервер: `Ctrl + C` в окне консоли.
