# STATE — playrelax

## Текущий статус
Сессия 3 (музыка) выполнена: плейлист на Howler.js, управление (плей/пауза,
следующий трек, shuffle), localStorage. Видео (Kinescope) — следующая сессия.
Ранее (сессия 2): структура src/, бесконечный режим, touch, адаптив.

## Что известно о прототипе (аудит от AI-партнёра)
- Один HTML-файл: ванильный JS + Canvas 2D, без фреймворков.
- Тетрис — классический туториал-код (движение, поворот, сброс линий,
  game over).
- Видеофон — iframe PeerTube (tube.tchns.de) с blur, z-index -99.
- Канвас 320x640, фигуры белые, opacity 0.70.
- Управление только клавиатурой (keydown, e.which) — на мобилке не работает.

## Известные проблемы прототипа (для TASKS)
1. Game Over противоречит ядру A — нужен бесконечный режим.
2. Нет touch-управления — блокер мобильной версии.
3. iframe PeerTube хрупок (чужой сервер, автоплей на iOS, костыльный
   масштаб) — заменить на управляемые `<video>`.
4. Всё в одном HTML — нет структуры.
5. Нет меню/паузы/смены мира.
6. Нет звука.
7. «Душа/тело» (инерция) не реализовано.
8. Канвас фиксированного размера — нет адаптива.
9. Видеофон пока заглушка `<video>` без источника — видео (Kinescope) в следующей сессии.
10. Аудио: треки-заглушки (assets/audio/track1..3.mp3) не существуют — реальные файлы добавить позже.

## Решения (зафиксировано)
- Ядро MVP = вариант A (релакс-тетрис + фон + смена миров).
- Стек: ванильный JS + Canvas 2D + `<video>`. Без фреймворков на старте.
- Имя проекта/папки: `playrelax`. Продуктовое имя в текстах: playrelax.
- «Душа/тело», частицы, звук, заставка, психологи — вне MVP (roadmap).

## Следующий шаг
Видеофон: Kinescope (или `<video>` + кроссфейд) + смена мира.
